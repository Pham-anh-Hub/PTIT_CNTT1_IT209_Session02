# BT-1: Mô tả các bước tạo Droplet và đăng nhập thành công với ssh key
* Tạo Droplet với DigitalOcean:
```
1. Đăng nhập DigitalOcean --> Click Create --> Droplets.
2. Region: Chọn Singapore.
3. Choose an image: Chọn Ubuntu (bản 22.04 LTS hoặc mới nhất).
4. Droplet Type: Basic --> Chọn loại Regular with SSD rẻ nhất (recommmend $4).
5. Authentication Method: Chọn SSH Key --> Click New SSH Key --> Dán nội dung file .pub vừa copy ở Bước 1 vào --> Đặt tên để nhớ (ví dụ: my-laptop-key).
6. Finalize: Đặt tên Hostname gợi nhớ (ví dụ: devops-lab-server) --> Click Create Droplet.
7. Đợi khoảng 30–60 giây, hệ thống hoàn tất và hiển thị địa chỉ IPv4 của server (ví dụ: 159.65.x.x).
```

* Cấp quyền - đăng nhập trực tiếp bằng ssh key:
```
1. Đăng nhập bằng mật khẩu cũ ssh "ssh root@diachiIP"
2. Chạy lệnh tạo thư mục và phân quyền
3. Mở file lưu key,
4. Khóa quyền file 
5. Ctrl + X - đăng xuất
```
* Kiểm tra đăng nhập - đăng nhập với ```ssh root@(địa chỉ ip máy chủ cấp)```: đăng nhập thẳng thành công với ssh key mà không cần nhập mật khẩu
