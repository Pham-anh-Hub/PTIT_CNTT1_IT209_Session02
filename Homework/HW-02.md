# BT2: Tổng hợp
* các lệnh Linux đã chạy để tạo user
* copy SSH Key
* phân quyền thư mục 
* log Terminal kiểm tra lệnh sudo whoami.

```
1. Khởi tạo User thường và cấp quyền quản trị (Sudo)**
- Tạo user mới tên là devops
adduser devops

- (Tùy chọn) Đặt lại mật khẩu nếu user đã tồn tại
passwd devops

- Thêm user devops vào nhóm quản trị sudo
usermod -aG sudo devops

```

**2. Sao chép cấu hình SSH Key**

```bash
# Cài đặt rsync (trong trường hợp máy chủ chưa có sẵn)
apt update
apt install rsync -y

# Sao chép thư mục SSH từ root sang user devops và tự động cấp quyền sở hữu
sudo rsync --archive --chown=devops:devops ~/.ssh /home/devops/

```

**3. Phân quyền thư mục SSH đảm bảo bảo mật**

```bash
# Phân quyền chỉ chủ sở hữu (devops) mới được xem và thực thi thư mục .ssh
chmod 700 /home/devops/.ssh

# Phân quyền chỉ chủ sở hữu (devops) mới được đọc/ghi file authorized_keys
chmod 600 /home/devops/.ssh/authorized_keys

```

**4. Kiểm tra đăng nhập và đặc quyền quản trị**

* **Lệnh đăng nhập từ máy cá nhân:**

```bash
ssh -i duong_dan_toi_file_key devops@<IP_ADDRESS_DROPLET>

```

* **Log Terminal kiểm tra lệnh sudo whoami sau khi đăng nhập thành công:**

```bash
devops@first-project-vm:~$ sudo whoami
[sudo] password for devops: 
root

```
